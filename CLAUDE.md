# TourOps Landing Page — Website Project

## What This Repo Is
This is the **touropsai.com marketing website**. It is deployed via Vercel. This is the single source of truth for the live TourOps website.

## What This Repo Is NOT
This is NOT the TourOps operations/AI assistant build project. Business docs, governing specs, and AI OS live in the `barleybus-tourops` repo.

## Structure
- `index.html` — single-file site (inline CSS + JS)
- Image assets: `founder-headshot.png`, `logo-color.png`, `logo-white.png`, `todd-nz.jpeg`
- Demo sites (Lone Star Shine, Abrams Fence) archived on `archive/demo-sites` branch

## Rules
- When working in this repo, you are building a **website** (HTML, CSS, JS, images).
- Do NOT create or modify files related to: pipeline stages, conversation design, regression tests, GHL schemas, n8n specs, prompt compilers, or any other operational/AI build artifacts.
- The website domain is https://touropsai.com
- The brand name is **TourOps** (not "OurOps", not "Tour Ops").
- Pricing and feature copy must match `barleybus-tourops/active/platform/business/tourops_tiers_and_positioning.md`.
